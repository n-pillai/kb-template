# example-data/kb — the starter private-data folder

You don't copy this by hand: `scripts/setup-private-repo.sh` installs it into your **private** data
repo at `private/kb/`, together with the checks and `auto-merge.yml` from
`../private-repo-files/`. Do not keep real content in this public repo.

Everything here is **illustrative**. The source, author and URLs are invented (they use
`example.com`), so the example entry, library card and theme show the formats, not real findings.
The setup script leaves those three out, so your knowledge base starts empty. The two example
projects in `projects.md` are installed; replace them with your own before your first `/triage`.
