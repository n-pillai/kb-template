# example-data/kb — a starter private-data folder

Copy this folder into your **private** data repo at `private/kb/`, then point the machinery at it
with `PERSONAL_DATA_DIR`. Do not keep real content in this public repo.

Everything here is **illustrative**. The source, author and URLs are invented (they use
`example.com`), so the example entry and card show the formats, not real findings. Delete them, and
replace the example project and theme, before your first `/distill`.
