# projects.md — the governed project lens

The list of what counts as a "so what for my work" tie (the other valid tie is an active
watch/confirmed theme in `THEMES.md`). Like `tags.md`, it is a governed vocabulary: `projects:`
frontmatter may only use slugs listed here. You edit this file by hand.

## Status vocabulary

- `active` — currently getting work hours. The default tie target.
- `parking` — deferred or paused, but still a valid tie.
- `dormant` — retired. **No longer a valid new tie.** Never delete a dormant project; move it to
  the section below so old entries' `projects:` references still resolve.
