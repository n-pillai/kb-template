Produce the KB digest (the push channel — the morning brief's KB section). Read-only over canonical files; it surfaces, it doesn't write.

## Output — three blocks

1. **New since yesterday** — entries committed since the cutoff (default: last 24h, or since $ARGUMENTS date). One line each: *source · thesis · so-what · signal tier*. Phrase each as a claim you can agree/disagree with without clicking.
2. **Theme movement** — anything in `$PERSONAL_DATA_DIR/private/kb/THEMES.md` that crossed a corroboration threshold (parking → watch, watch → confirmed) in the window, with the sources that moved it. Note same-author / not-fully-independent caveats.
3. **Awaiting your nod** — pending Tier-B concept-graph proposals (from `/distill` runs that staged `$PERSONAL_DATA_DIR/private/kb/wiki/` changes) in `$PERSONAL_DATA_DIR/private/kb/_inbox/proposals/`. Format: "This batch touches these concept pages: [list]. Approve all / edit / skip?"

Keep it tight — headline first, links for drill-down. This is the headline; `/distill` output and the entries are the article.
