# tags.md — governed tag list

Tags are a small, governed vocabulary — new tags are *proposed* during `/distill`, not invented ad
hoc, so the namespace stays useful. Keep them broad and reusable (a tag that applies to one entry
isn't a tag). The set below is an example; replace it with your own.

## Active tags

- `agents` — agentic systems, agent-as-user, multi-agent
- `ai-adoption` — how people and organizations actually adopt AI
- `evals` — measuring LLM/agent output quality: error analysis, pass/fail criteria, judges
- `judgment` — taste, decision quality, what to build
- `writing-craft` — getting a piece read and acted on: audience, structure, specificity, revision
- `knowledge-work` — how individuals capture, synthesize and reuse what they learn

## Proposing a new tag

During `/distill`, if no active tag fits, propose one with a one-line definition and add it here in
the same change. Prefer reusing an existing tag over near-duplicates.
